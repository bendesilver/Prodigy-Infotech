# 🔐 Image Encryption Tool v2.0

![Python Version](https://img.shields.io/badge/python-3.6+-blue.svg)

A professional image encryption/decryption tool using XOR cipher, developed by Ben De Silver as a project.

## ✨ Features
- 🔒 XOR-based image encryption/decryption
- 🖼️ Multiple image format support (PNG, JPG, BMP, GIF, TIFF)
- 🎯 Interactive menu & command-line modes
- 📊 Progress visualization
- 🔑 Secure key handling

## 🚀 Quick Start
# Run interactive mode(Recommended):
```
python image_tool.py
```

# Install dependencies
```
pip install -r requirements.txt
```

# Encrypt an image
```
python image_tool.py --encrypt input.jpg output.png --key "password"
```

# Decrypt an image
```
python image_tool.py --decrypt encrypted.png output.jpg --key "password"
```

# Setup environment (Linux/Mac)
```
 ./setup_env.sh

```
# Setup environment (Windows)

Double click in setup_env.bat

# Run CLI mode
```
python image_tool.py --encrypt photo.jpg encrypted.png --key "password"
```

# Clone repository
```bash
git clone https://github.com/bendesilver/PRODIGY_CS_02.git
```
# Check dependencies
```
python image_tool.py --check-deps
```
