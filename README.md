# Prodigy Infotech Internship Projects

This repository contains three projects completed during my internship at Prodigy Infotech. Each project focuses on different aspects of cybersecurity and data protection.

## 📁 Projects Overview

### 1. 🔠 Caesar Cipher Algorithm
A classical cryptography implementation that allows users to encrypt and decrypt text using the Caesar Cipher method. This educational tool demonstrates fundamental encryption concepts.

**Key Features:**
- Customizable shift key (1-25)
- Handles both uppercase and lowercase letters
- Preserves numbers, symbols, and whitespace
- Includes brute-force decryption option for demonstration


### 2. 🖼️ Image Encryption Tool
A secure image encryption/decryption application that protects visual data using cryptographic algorithms. This tool ensures confidential images remain private during storage and transmission.

**Key Features:**
- Supports multiple image formats (PNG, JPG, BMP)
- Implements AES encryption for high security
- Maintains image metadata after encryption

### 3. 🔐 Password Strength Checker
A Python-based tool that evaluates password strength by analyzing multiple security parameters. This tool helps users create stronger passwords by providing real-time feedback and suggestions.

**Key Features:**
- Checks password length and complexity
- Detects common patterns and dictionary words
- Provides strength score and improvement suggestions


## 🛠️ Technologies Used

- **Programming Language:** Python 3.x
- **Libraries:** 
  - Pillow/PIL (for image processing)
  - Cryptography (for encryption algorithms)
  - Regex (for pattern matching in passwords)

## 📋 Prerequisites

Before running these projects, ensure you have:

1. Python 3.7 or higher installed
2. Required libraries (install via requirements.txt)
3. Sufficient storage for image files (for Image Encryption project)

## 🔧 Installation

1. Clone this repository:
```bash
git clone https://github.com/bendesilver/Prodigy-Infotech.git
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```
